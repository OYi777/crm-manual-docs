    第一章 注册流程

    一、旧版流程（Group+HK）

      第一步：用户基础信息录入：
      1）邮箱：填写有效可用的电子邮箱，作为账号唯一登录标识；
      2）密码：设置8-12 位密码，需包含大小写字母 + 数字组合；
      3）推荐码：填写专属推荐码；[注释见本文路径：第三章首页\2.普通用户视角\2.1.1推荐码]
      4）开通交易账户类型：用户需在「标准账户/USD」与「美分账户/USC」之间二选一；
      5）验证码：输入图片中显示的验证码内容；
      6）协议确认：勾选《注册条款》我本人知晓和同意上述所有条款选项；
      7）提交注册：确认所有信息无误后，点击「提交注册」按钮，完成注册申请。

      第二步：用户账号激活（二选一）：
      根据管理员参数配置[注释见本文路径：第十章系统管理\二、配置参数\1.开户参数\1.1【注册自动激活】功能说明]， 选择以下任意一种方式完成账号激活：
      方式一，邮件激活：
      提交注册后，系统将激活邮件发送至注册邮箱，点击邮件内的验证链接完成账号激活，激活成功后可登录账号并进入实名认证页面；

      方式二，自动激活：
      提交注册后，系统自动完成账号激活，无需邮件验证，可直接登录账号并进入实名认证页面。

      第三步：用户实名认证：
      登录账号后，按步骤引导进入「完善资料」页面。

      1）信息填写（必填项）：地区、手机号（含区号）、真实姓名、出生日期、证件类型、证件号码、居住地信息。
      2）材料上传：按系统提示上传证件正反面照片，需保证照片为清晰实拍、信息完整无遮挡，禁止翻拍或截图。
      3）提交申请：确认所有信息无误后，点击「提交」按钮，提交实名认证申请开通MT账号。

      第四步：开通MT账号，用户即可正常入金、交易等操作。[相关开通MT账号流程规则见本路径：第八章客户管理\二、账户审核]。

    二、新版流程（HK）

    前置生效条件

    用于指导 HK 版本4步式个人开户全流程操作；后台配置开关「是否开启 hk 新注册」为【是】时，本注册流程生效；开关为【否】则跳转旧版流程，不适用本流程。

    开关配置文档路径：第十章系统管理\三、配置参数\1.开户参数\1.3【是否开启hk新注册】功能说明。

    整体流程链路：

    登录页面 → 点击「去注册」进入【步骤 1 个人资料】→【步骤 2 银行数据】→【步骤 3 上传证明文件】→【步骤 4 投资者问卷】→ 提交开户申请 → 提交成功弹窗 → 可跳转登录开户审核进度查询页。

    不同注册入口/链接对应的【步骤4投资者问卷】展示规则

    注册渠道 / 链接类型 配置规则说明 步骤 4 投资者问卷展示效果 分组绑定逻辑
    客户管理 - 专属分享链接 （一般投资者） 后台为代理配置专属「一般投资者」分享注册链接，用户侧首页推广板块展示该链接 直接隐藏【步骤4投资者问卷】环节，无需填写问卷 注册完成后自动绑定预设的一般投资者分组
    客户管理 - 专属分享链接 （专业投资者） 后台为代理配置专属「专业投资者」分享注册链接，用户侧首页推广板块展示该链接 仅展示【专业投资者】单选选项，无一般投资者选项 注册完成后自动绑定预设的专业投资者分组
    用户侧首页普通代理直客链接 用户从首页推广板块复制通用普通代理直客链接注册 直接隐藏【步骤4投资者问卷】环节，无需填写问卷 无投资者分组绑定动作
    登录页「去注册」+ 填写非指定推荐码 用户登录页点击「去注册」，录入未做投资者分组配置的普通推荐码开户 直接隐藏【步骤4投资者问卷】环节，无需填写问卷 无投资者分组绑定动作
    登录页「去注册」+ 填写指定推荐码 用户登录页点击「去注册」，录入后台已配置投资者分组权限的指定推荐码开户 完整展示【一般投资者】、【专业投资者】两个可选选项，需手动选择 用户勾选对应类型后，账户绑定对应投资者分组

    1.用户侧注册操作步骤

    第一步：登录页面进入注册页面

    页面元素

    登录表单：邮箱、密码、图形验证码（用于已有账号登录）

    注册入口：【没有账号？去注册】（橙色文字链接，跳转开户步骤 1）

    辅助功能：忘记密码、开户审核进度查询

    操作步骤

    无需填写登录信息，直接点击【去注册】；

    系统校验后台开户开关，开关开启则进入 4 步新版开户表单；开关关闭跳转旧版注册。

    补充入口：底部【开户审核进度查询】，可输入邮箱查询已提交开户单据审核状态。

    模块 1：登录信息设置（全部必填）

    电子邮箱地址 ：标准邮箱格式，系统全局唯一，已注册邮箱无法重复提交，失焦自动校验格式；

    登录密码/确认密码：设置8-12 位密码，需包含大小写字母 + 数字组合，两次输入密码必须完全一致；

    推荐码：

    场景 1：拥有上级代理推荐码，直接输入文本框，绑定代理关系；

    2.用户侧开户审核进度查询操作指南

    登录页面底部【开户审核进度查询】按钮，点击弹出【查看审核进度】弹窗；

    3）返佣金额计算规则

    ①固定金额计算规则如下：

    A.1大手为基础分佣模板配置的“固定金额”

    B.返佣金额=交易量（手）固定金额分佣比例

    例子：

    I.假如A1是一级代理，A2是A1下的二级代理，B是A2下的直客，B的MT分组为a

    II.假如以黄金为例，基础分佣模板中配置黄金的固定金额为15美元

    III.配置A1中MT分组为a的分佣比例，配置A1分佣5美元（比例），A2分佣10美元（比例）

    IV.假如B直客交易了黄金，交易量为0.01手，注意这里1大手为15美元，0.01手为0.15美元，那么A1获得返佣0.75美元，A2获得返佣1.5美元

    ②点值计算规则如下：

    交易品种是非外汇或者品种或者名称不包含USD

    交易品牌CurrencyProfit为USD = 品种合约单位品种每1点子返佣点数*手数

    假如配置基础分用模板点值为10，交易量（即手数）0.01

    例子1：

    交易品种名称EURXYD CurrencyProfit：USD 品种每1点子0.00001，品种合约单位100000

    分佣金额：100000.0000110*0.01

    交易品牌CurrencyProfit为XXX = 品种合约单位品种每1点子返佣点数手数（获取XXXUSD当前交易平仓时间之前的最近的一条交易记录的价格）

    例子2：

    交易品种名称CHFABD CurrencyProfit：CHF 品种每1点子0.00001，品种合约单位100000,获取CHFUSD当前交易平仓时间之前的最近的一条交易记录的价格2.4

    分佣金额：100000.00001100.012.4

    交易品牌CurrencyProfit为XXX = 品种合约单位品种每1点子返佣点数*手数 /（获取USDXXX当前交易平仓时间之前的最近的一条交易记录的价格）

    例子3：

    交易品种名称OPUCNH CurrencyProfit：CNH 品种每1点子0.00001，品种合约单位100000,获取USDCNH当前交易平仓时间之前的最近的一条交易记录的价格3.2

    分佣金额：100000.0000110*0.01/3.2

    交易品种是 外汇或者品种，名称不包含USD

    交易品牌名称前3个字符不是USD = 品种合约单位品种每1点子返佣点数手数

    例子4：

    交易品种名称XAGXDD CurrencyProfit：XAD_ 品种每1点子0.00001，品种合约单位100000,最近的一条交易记录的价格3.2

    分佣金额：100000.0000110*0.01

    其他交易品种USD = 合约单位每1点子返佣点数手数/当前交易MarketBid值

    例子5：

    交易品种名称USDGKD CurrencyProfit：XKL 品种每1点子0.00001，品种合约单位100000,当前交易记录的MarketBid为1.3

    分佣金额：100000.0000110*0.01/1.3

    3.3净入金奖励配置

    为独立奖励核算体系，与基础返佣、交易奖励完全隔离，用于管控当前销售名下客户净入金达标奖励的发放规则。 本模块可自定义是否开启净入金奖励、核算口径、计算起始时间、交易手数门槛、奖励计提标准与结算周期；系统将按照配置自动校验客户入金、交易数据，达标后核算对应净入金奖励并归属该销售。

    注意：前置基础通用规则——“交易手数累计与清空规则”，客户交易手数为周期内持续累积计算；当客户同时满足「交易手数门槛、净入金达标」两大条件、系统触发净入金奖励发放后，该客户当期已累计的全部交易手数立即清零，下一周期重新从零累计交易手数。

    是否开启净入金奖励

    选择「否」：模块内剩余所有配置项（除「计算开始时间」）全部隐藏，无需填写；该销售名下所有客户，无论净入金、交易数据是否达标，均不产生任何净入金奖励；

    选择「否」：仅统计本销售规则创建启动后新增的净入金，规则生效前的历史入金数据不参与累计核算；

    是否计算历史交易量

    选择「是」：统计客户周期交易手数时，叠加纳入规则创建生效前的历史交易手数，合并累计后判断是否达到交易手数门槛；

    计算逻辑

    客户同时达标交易手数门槛、净入金门槛后，净入金奖励公式：

    下一周期核算时，合并计算「当期新增交易手数 + 上期结转交易手数」。

    本期净入金正负余额不达标门槛跨期结转规则：

    若当期客户累计净入金总额为负数：当期不生成任何净入金奖励，该负差额自动结转至下一结算周期；

    若当期客户累计净入金总额为正数：当期不生成任何净入金奖励，该负差额自动结转至下一结算周期；

    下一周期核算时，合并计算「当期新增净入金 + 上期结转正/负余额」。

    返佣规则

    4.1基础定义

    返佣基数：以用户实际交易手数为基数，按交易品种、对应等级的返佣标准计算；

    结算前提：仅活动有效期内的平仓订单参与返佣结算，订单平仓后按规则生成返佣记录。

    4.2结算规则（按链路逐级向上结算）

    基础结算逻辑

    从交易用户开始，沿推荐链路向上，对每一级直接上级按「上级返佣标准 - 下级返佣标准」×交易手数计算差额返佣。

    若差额≤0（即下级等级≥上级等级），该上级无返佣。

    同一链路中，若下级已获得该交易的返佣，上级与下级同等级时，上级不再重复结算。

    不同等级关系的结算规则

    等级关系 结算规则 示例
    下级等级<上级等级 上级获得差额返佣：(上级标准-下级标准) ×交易手数 下级2级（返佣标准44），上级3级（46）：(46-44)×手数
    下级等级=上级等级 上级无返佣（同一链路仅结算一次差额） 下级3级，上级3级：无返佣
    下级等级>上级等级 上级无返佣 下级3级，上级2级：无返佣

    示例场景完整结算如下（以test-a3-1交易0.12手原油为例）

    链路：test-a3-1（0级/直客） → test-a3（2级） → test-a2（3级） → test-a1（3级） → test-测试-A（5级）

    假设等级排序：0级 < 1级 < 2级 < 3级 < 4级 < 5级

    假设原油返佣标准：

    等级 0级 1级 2级 3级 4级 5级
    原油返佣（美元/手） 0 40 44 46 48 50

    返佣规则

    4.1基础定义

    返佣基数：以用户实际交易手数为基数，按对应返佣标准计算（例：交易0.1手，基数按0.1 手计算）。

    等级优先级：直客 < RIB < IB < MIB < VIB < PIB，返佣按上级 > 下级的规则执行，下级≥上级时不产生额外返佣。

    返佣类型：分为「等级差额返佣」和「平级奖励返佣」，两种规则不穿透隔代结算，仅在相邻上级生效。

    4.2各产品等级返佣标准
    等级 外汇（美金/手） 黄金（美金/手）
    直客 0 0
    RIB 0 10
    IB 6 12
    MIB 8 14
    VIB 10 16
    PIB 12 18

    注：平级奖励固定为 0.5 美金/手，不区分产品类型。

    4.3结算规则

    基础结算前提

    仅对活动有效期内产生的交易数据结算返佣，活动结束后的数据不参与返佣。

    返佣按用户当前有效等级对应的产品返佣标准计算，未达到等级条件的，按当前等级结算。

    上下级结算规则（按链路逐级向上结算）

    场景 A：下级等级 < 上级等级（等级差额返佣）

    规则：相邻上级获得「上级返佣标准 - 下级返佣标准」× 交易手数 的差额返佣。

    例：下级为 MIB（白银返佣 20），上级为 VIB（白银返佣 25），交易 0.1 手白银时，上级 VIB 获得：(25-20)×0.1=0.5美金。

    场景 B：下级等级 = 上级等级（平级奖励返佣）

    规则：

    仅首个出现的直接上下级同等级节点，可获得平级奖励（0.5 美元 / 手 × 交易手数）；

    例：下级为MIB，上级为MIB，交易0.1手白银时，上级 MIB 获得：0.5×0.1=0.05美金。

    同一链路中，若下级已领取平级奖励，其上一级同等级人员不再发放任何返佣。

    例：test-吴中责（MIB）的上级为 test-沈晗萌（MIB），test-吴中责已获得下级交易的平级奖励，则test-沈晗萌不再获得该笔交易的平级奖励

    隔代平级不穿透结算，仅直接上下级同等级时触发。

    场景 C：下级等级 > 上级等级

    规则：上级等级低于下级，无任何返佣。

    例：下级为VIB，上级为RIB，交易时上级 RIB不获得任何返佣。

    规则说明

    1.1消息状态

    启用状态：符合推送条件的用户将按设置的推送方式触发消息弹窗展示；

    禁用状态：无论用户是否符合推送条件，PC 端与移动端均不会展示该消息弹窗，也不会触发任何推送动作。

    1.2推送人群
    推送人群 覆盖用户范围
    全部 平台内所有代理、直客用户
    代理 仅平台代理角色用户
    直客 仅平台直客（普通用户）角色
    1.3推送方式
    推送方式 触发逻辑 补充说明
    首次登录 用户首次登录系统时触发弹窗，后续所有登录操作均不再触发 仅对用户的首次登录行为生效，无重复触发
    每日首次登录 用户每日首次登录系统时触发弹窗，当日后续登录不弹窗，次日首次登录自动重置触发 按自然日重置规则，每日仅触发 1 次
    每次登录 用户每次登录系统时均触发弹窗，无次数与周期限制 每次登录行为都会触发消息展示

    客户触达数：

    计算公式：统计周期内，销售在系统内添加过至少一次跟进记录的排重客户数； *排重逻辑说明：统计的是“人数”而非“次数”。例如对同一个客户添加了 5 条跟进记录，客户触达数仍计为 1。

    平均跟进频次：计算公式：总跟进次数 / 客户触达数

    无效/退回占比：计算公式：(无效线索数 + 退回公海数) / 分配线索总数 * 100%

    首次入金率：计算公式：(首次入金数 / 分配线索总数) * 100%。保留两位小数

    贡献净入金；计算公式：总入金 - 总出金（统计周期内该销售名下所有客户）

    3.1【是否开启有入金才返佣】功能说明

    入口路径：系统管理-配置参数-返佣参数

    该配置用于控制返佣触发条件，决定客户是否需要完成入金，才能产生交易返佣，具体规则如下：

    配置为「否」（关闭有入金才返佣）

    客户无论是否完成入金，只要产生交易，均会正常触发返佣：

    代理客户交易：自身交易返佣正常发放，上级代理返佣同步发放；

    直客客户交易：自身不产生返佣，但上级代理返佣正常发放。

    配置为「是」（开启有入金才返佣）

    客户需完成入金后产生的交易，才会触发返佣，无入金交易不产生任何返佣：

    审批提醒

    为 CRM 后台左侧菜单栏的审批类模块增加红色数字角标待办提醒，直观展示当前登录管理员有权限处理的待审批单据总量，帮助管理员快速定位待办工作，降低漏审、逾期审核风险。 本功能属于全局底层通用能力，统一兼容多级审批（待审核出金）与一级审批（待审核银行卡、账户审核） 两种流程场景。

    待办数量计算公式

    待办数量 = 管理员拥有菜单访问权限 && 单据当前审核节点归属该管理员处理范围 && 单据匹配对应模块待办状态；

    提醒数量展示逻辑：待办 = 0 时完全隐藏角标；1~99 展示真实数字；待办数量＞99 统一显示「99+」；

    菜单审批提醒汇总逻辑

    菜单层级 统计规则
    一级菜单（出入金） 汇总旗下所有支持提醒的二级审批模块待办总数：待审核出金待办数量 + 待审核银行卡待办数量
    二级菜单（待审核出金/待审核银行卡/账户审核） 仅统计当前模块、归属本人节点的待办单据

    分模块细化状态口径：

    待审核出金（会签双节点流程：客服、风险）

    客服角色待办统计条件：单据状态 = 会签审核 + 会签审核中

    风险角色待办统计条件：单据状态 = 会签审核 + 会签审核中

    注意：会签流程特殊计算规则

    单据处于「会签审核」：客服、风险两边审批提醒同步计入该单据；任意一方完成审批后，本方待办数量-1，另一方数量保持不变。

    单据流转至「会签审核中」：单据仍保留在未完成审批的角色待办统计内，已完成审批的角色不再统计该单据。

    示例：

    现有10条状态为【会签审核】的出金单据：客服、风险菜单角标均展示10； 风险完成1条审批后，风险审批提醒变为9，客服仍为10；该条已审批单据流转为【会签审核中】，风险审批提醒维持9，客服依旧为10。

    待审核出金（财务单节点流程）

    财务角色待办统计条件：单据状态 = 财务审核

    待审核银行卡、账户审核（一级单节点流程）

    待办统计条件：单据状态 = 未审核
